# Snip Design System

Compact visual language for the frontend.

## Tokens

- Background: `--bg-0: #070707`, `--bg-1: #0d0d0f`
- Surface: `--surface: rgba(20,20,24,0.82)`, `--surface-strong: rgba(28,28,34,0.92)`
- Text: `--text: #f6f6f7`, `--muted: #a6a6af`
- Accent: `--accent: #ff855f`, `--accent-2: #ff5d86`, `--accent-3: #ffb26b`
- Gradient: `--hero-glow: radial-gradient(1200px 420px at 50% 0%, rgba(255,133,95,0.36) 0%, rgba(255,93,134,0.22) 45%, rgba(255,178,107,0.12) 62%, rgba(7,7,7,0) 100%)`
- Font stack: `"Space Grotesk", "Manrope", "Avenir Next", "Segoe UI", sans-serif`
- Type scale: hero `clamp(2rem, 5vw, 3.8rem)`, body `1rem`, label `0.9rem`
- Spacing: `--space-1: 0.5rem`, `--space-2: 1rem`, `--space-3: 1.5rem`, `--space-4: 2.5rem`
- Radius: `--radius-pill: 999px`, `--radius-card: 22px`, `--radius-soft: 14px`
- Borders: `1px solid rgba(255,255,255,0.12)`
- Shadows: `0 16px 44px rgba(0,0,0,0.45)`, glow ring `0 0 0 1px rgba(255,133,95,0.22)`

## Mapping

- Header becomes the centered hero block with warm glow atmosphere.
- URL form becomes a pill-shaped chat input with attached action button.
- Success and error notices become subtle rounded status chips.
- Links table lives inside a rounded glass-like card with quiet borders.
